# VaultPix 设置说明

本页解释设置界面的每个分类。所有更改都会自动保存到当前 Vault。

## 基础行为

- **启用图片处理**：关闭后不再接管粘贴和拖拽；图片管理器和手动命令仍可使用。
- **工作模式**：自动模式上传到云端；半自动模式只在本地优化；手动模式只响应命令。
- **处理粘贴图片 / 处理拖入图片**：分别控制两个入口。手动模式下自动禁用。

## 上传服务

| 字段 | 作用 |
|---|---|
| Endpoint | 插件调用对象存储 API 的地址，不是图片展示地址 |
| Region | Bucket 所在地域；必须与服务商控制台一致 |
| Bucket | 存放图片的存储桶名称 |
| Access Key ID | API 凭证的公开标识 |
| Secret Access Key | API 凭证的秘密部分，绝不能公开 |
| 公共访问域名 | 最终写入 Markdown 的 URL 前缀，必须允许匿名读取 |
| 路径前缀 | 可选的远程顶层目录，例如 `notes` |
| Path Style | 只有明确要求路径式访问的 S3 兼容服务才开启 |

Cloudflare R2 的 Region 通常为 `auto`。阿里云 OSS 会根据 Region 自动生成 S3 兼容 Endpoint，并强制关闭 Path Style。

连接测试只读取 Bucket 元信息，不上传文件。第一次实际上传时，VaultPix 会继续验证最终图片 URL。

## 图片优化

- **WebP**：推荐默认值，兼顾清晰度、透明背景和体积。
- **JPEG**：适合照片，不支持透明背景。
- **PNG**：无损但通常更大。
- **AVIF**：压缩率高，但能否编码取决于当前 Obsidian/Electron。
- **保持原格式**：不重新编码，也不会清理图片元数据。

“限制最长边”适合大多数截图和照片。开启“禁止放大小图”可避免小图插值变糊。

## 命名与远程目录

文件名模板不需要扩展名。常用变量：

- `{noteName}`：笔记名
- `{fileName}`：原图片文件名
- `{folderName}`：笔记所在目录名
- `{vaultName}`：Vault 名称
- `{YYYY}`、`{MM}`、`{DD}`：日期
- `{index}`：同一次任务内的图片序号
- `{hash:12}`：指定长度的内容摘要
- `{uuid}`：随机 UUID
- `{frontmatter:key}`：读取笔记 frontmatter 字段

推荐的冲突策略是 Hash。相同内容可复用地址，不同内容不会覆盖原对象。

## 链接与本地备份

默认图片对齐为居中。全局设置作用于没有单独指定对齐的图片；命令面板中的单图设置优先。

迁移成功后推荐移动到 `.vaultpix-backup/`。只有远程上传、URL 验证、所有笔记写入和回读校验都成功后，插件才处理本地原图。

## 任务与诊断

- 并发上传数：默认 3；网络不稳定或服务限流时降至 1–2。
- 失败重试次数：仅对暂时性错误有帮助，凭证错误不会因重试恢复。
- 网络超时：公开 URL 验证的等待时间。
- 验证公开图片地址：强烈建议保持开启。
- 维护资产清单：为去重、图片管理器和迁移恢复提供数据。
- 日志详细程度：正常使用保持“信息”，排错时临时切换为“调试”。
